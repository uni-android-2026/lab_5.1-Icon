# Практическая работа №5

## Описание
Задача работы заключалась в замене стандартной иконки Android-приложения на собственный адаптивный вариант.

## Что было сделано
1. Подготовлен пользовательский графический ресурс для основной иконки приложения.
2. На его основе сформирован набор launcher-иконок для разных плотностей экрана.
3. Созданы ресурсы `my_logo`, `my_logo_round` и `my_logo_foreground`.
4. В манифесте изменены параметры `android:icon` и `android:roundIcon`, чтобы приложение использовало новые ресурсы.
5. Базовый экран активности сохранён как простой экран-проверка.

## Результат
После выполнения работы приложение запускается уже с собственной адаптивной иконкой, что закрепляет работу с `mipmap` и настройками манифеста.
